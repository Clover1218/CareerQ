# 《职问桥》前后端接口契约 v1

> 项目代号：**CareerQ**　｜　对外名称：**职问桥**
> 编写：**DeepSeek**（AI 协助）　｜　日期：2026-11-14　｜　状态：**草案 v1.1（供前后端联调）**
> 适用：后端 **Spring Boot**（用户负责前后端连接）＋ 前端 **Vue3 + TypeScript**（队友负责）
> 已定：**鉴权采用 Cookie 会话 + CSRF Token**；Qoder Sites 暂按「只托管前端静态资源」推进。
> 方法：本文件是前后端唯一契约；**以本文件 + OpenAPI 文档为准，前端不得依赖后端内部实现**。

---

## 0. 约定

| 项 | 约定 |
|---|---|
| 基础路径 | `/api/v1` |
| 数据格式 | JSON，UTF-8；时间 ISO-8601（如 `2026-11-14T17:20:00+08:00`） |
| 鉴权 | **会话 Cookie（已定）**：`HttpOnly; Secure; SameSite=Lax` + CSRF Token；不使用 localStorage 存令牌 |
| 分页 | 游标分页：`?cursor=<opaque>&limit=20`；响应 `{items:[], nextCursor:null}` |
| 幂等 | 写接口支持 `Idempotency-Key: <uuid>`，同键 24h 内重复请求返回首次结果 |
| 错误体 | `{ "code": "QUESTION_NOT_FOUND", "message": "问题不存在", "requestId": "..." }` |
| 状态码 | 200/201 成功；400 参数错误；401 未登录；403 无权限；404 不存在；409 冲突；429 限流；500 服务异常 |
| 角色 | `student` / `hr` / `operator` / `admin` |
| CORS | 仅允许前端域名；本地开发用 dev server 代理 `/api` 到 Spring Boot |

## 1. 鉴权与用户

### POST `/api/v1/auth/sms-code`
发送手机验证码（严格限流：IP 5 次/小时、手机号 5 次/天）。
```json
{ "phone": "13800000000" }
```

### POST `/api/v1/auth/login`
手机号 + 验证码登录，成功返回会话 Cookie（或 token）。
```json
{ "phone": "13800000000", "code": "123456" }
```
响应：
```json
{ "user": { "id": "u_1", "role": "student", "nickname": "小明" } }
```

> **dev 环境验证码固定为 `123456`**（不发送真实短信）；生产接入短信供应商后关闭该模式。

### POST `/api/v1/auth/logout`
注销当前会话。

### POST `/api/v1/auth/hr-verify`
提交 HR 认证材料（multipart 或 JSON 引用存储 ID）。
```json
{ "companyDisplay": "某互联网公司", "industry": "互联网", "position": "HRBP", "materialRef": "storage_xxx" }
```
响应：`{ "verifyStatus": "pending" }`

### GET `/api/v1/me`
当前用户信息与角色。
```json
{ "id":"u_1","role":"student","nickname":"小明","school":"某大学","major":"计算机","hrVerifyStatus":null }
```

## 2. 问题（公开 / 私密）

### POST `/api/v1/questions`
提问，`scope` 决定公开或私密。
```json
{
  "scope": "public",
  "title": "实习面试一般会问什么？",
  "body": "……",
  "tags": ["实习", "面试准备"]
}
```
响应：`{ "id": "q_1", "status": "pending_machine" }`

### GET `/api/v1/questions?scope=public&tag=实习&cursor=&limit=20`
公开问题列表（仅 `published`）。

### GET `/api/v1/questions/mine?scope=private`
我的问题（含私密 Q1..Qn 与状态）。需登录。

### GET `/api/v1/questions/{id}`
问题详情。私密问题仅作者、指派 HR、运营可读；无权限返回 403。

### POST `/api/v1/questions/{id}/followups`
追问（公开或私密按问题 scope）。
```json
{ "body": "那简历应该写几页？" }
```

### POST `/api/v1/questions/{id}/close`
提问者确认关闭私密问题并归档。仅作者。

### POST `/api/v1/questions/{id}/publish`
私密问题申请脱敏公开（二次审核）。
```json
{ "anonymize": true }
```

## 3. HR 问题池与回答

### GET `/api/v1/hr/question-pool?tag=&cursor=`
公开未回答/待回答池（按时间排序）。

### GET `/api/v1/hr/private-pool?cursor=`
私密待认领池（展示脱敏摘要，不含提问者身份）。

### POST `/api/v1/hr/questions/{id}/claim`
认领私密问题 → `assigned_hr_id = 当前 HR`。

### POST `/api/v1/questions/{id}/answers`
回答问题（公开或私密）。
```json
{ "body": "……", "lengthType": "detailed" }
```
`lengthType`: `one_liner` | `detailed`。

## 4. 互动与内容

### POST `/api/v1/interactions`
点赞 / 收藏 / 标记有用。
```json
{ "targetType": "answer", "targetId": "a_1", "type": "useful" }
```

### GET `/api/v1/posts?cursor=` / POST `/api/v1/posts`
观点帖列表 / 发布（HR）。

### GET `/api/v1/feed/highlights`
本周精选。

### POST `/api/v1/reports`
举报。
```json
{ "targetType": "answer", "targetId": "a_1", "reason": "spam", "detail": "..." }
```

## 5. 运营后台（RBAC：operator / admin）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/admin/moderation/queue?status=pending` | 审核队列（按风险×等待排序） |
| POST | `/api/v1/admin/moderation/{id}/decide` | `{ "decision": "approve"\|"reject"\|"remove", "note": "..." }` |
| POST | `/api/v1/admin/moderation/words` | 词库热更新 |
| GET | `/api/v1/admin/metrics` | 回应率/时长/积压/沉淀率 |
| GET | `/api/v1/admin/private/{id}` | 审阅私密内容（**写审计日志**） |

## 7. 状态枚举（前后端共用）

- `Question.status`：`pending_machine` / `pending_human` / `published` / `rejected` / `closed` / `public_pending` / `public_archived` / `removed`
- `scope`：`public` / `private`
- `Answer.lengthType`：`one_liner` / `detailed`
- `HR verifyStatus`：`pending` / `verified` / `rejected`

## 8. 前后端联调流程（建议）

1. 后端先用 springdoc 生成 OpenAPI（`/v3/api-docs`、`/swagger-ui`），前端据此生成类型与 mock。
2. 前端本地 dev server 代理 `/api` → `http://localhost:8080`，避免 CORS。
3. 契约变更**先改本文件**并在 PR 说明，前后端同步评审，禁止后端单方面改字段。
4. 联调顺序：鉴权 → 公开列表/详情 → 提问 → HR 回答 → 互动 → 私密工单 → 审核后台。
