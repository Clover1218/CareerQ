## 1. 分工

| 角色 | 负责 |
|---|---|

## 2. 依赖关系

```text
M0 ── M1 ── M2 ──┬── M3 ──┬── M4
                 │        └── M5
                 └── M6（前端可并行，按契约 Mock）
```

- 前端从 M1 起即可按 [`接口契约-职问桥.md`](接口契约-职问桥.md) 造 Mock 并行开发。
- M4 依赖 M2（身份）与 M3（问答基础）。
- M5 与 M4 可并行，但上线前必须完成。

## 3. 当前状态

- 已完成：产品方案（方案 C）、技术方案 v0.5、接口契约 v1.1、数据库设计、部署拓扑。
- 环境实测：Java 11（不满足 Boot 3）、Maven ✅、Node ✅、Docker ❌、PostgreSQL ❌。
- **阻塞项**：
  1. 需安装 JDK 21（或改用 Spring Boot 2.7 + Java 11，不推荐）。
  2. 数据库最终选 PostgreSQL 还是 MySQL（默认 PostgreSQL）。
- 下一步：完成 M0，然后 M1 生成后端骨架。

## 4. Definition of Done（每个里程碑）

- 代码能编译、测试可运行；
- 接口与 [`接口契约-职问桥.md`](接口契约-职问桥.md) 一致，变更先改契约；
- 提交正文写明「改了什么 / 为什么 / 验证结果」；
- 改动走独立分支 + PR（与仓库现行协作规范一致）；
- 文档与 `MEMORY.md` 同步更新。

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| Java 版本不满足 Boot 3 | 安装 JDK 21；Maven `toolchains` 固定版本 |
| 本地无 PostgreSQL | dev 用 H2 + PostgreSQL 兼容模式；Flyway 保持方言中立 |
| 前端并行开发阻塞 | 契约先行 + Mock 数据，前端不依赖后端进度 |
| 私密工单合规漏洞 | 私密内容同审核、运营可审阅、公开前二次审核 + 脱敏 |
| 范围膨胀 | 严格按 M3/M4 契约实现，非契约功能不进 MVP |
