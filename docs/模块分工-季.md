## 2. 后端现状（已具备）

### 账号与权限
- `POST /api/v1/auth/sms-code`、`/auth/register`、`/auth/login`、`/auth/logout`、`GET /api/v1/me`
- 注册默认 `student`；登录/注册分离（未注册登录返回 `40401`，重复注册 `40901`）
- 所有写接口强制 CSRF（含登录/注册）；`@PreAuthorize` 控制 HR/运营/管理员操作
- 运营接口统一 `/api/v1/admin/**`，仅 `OPERATOR`/`ADMIN`

### 学生提问
- `POST /api/v1/questions`（`scope=public|private`，公开问题走机审，私密问题直接转人工）
- `GET /api/v1/questions/{id}`（作者可看自己未公开问题；私密问题对非参与人 403）
- `POST /api/v1/questions/{id}/close`、`POST /api/v1/questions/{id}/publish`（私密结单后申请脱敏公开）
- `GET /api/v1/questions/mine?scope=&cursor=&limit=`（我的问题，游标分页；由 Codex 并行实现）

### 运营审核
- `GET /api/v1/admin/moderation/queue`：四类待审内容（question/answer/followup/public_post）
- **本次新增上下文**：队列项增加 `questionId`、`questionTitle`、`authorId`、`authorNickname`，便于审核时定位问题与作者
- `POST /api/v1/admin/moderation/{targetType}/{id}/decide`（approve/reject/remove，支持公开稿 publicCopy）
- `GET/POST /api/v1/admin/moderation/words` 词库管理；`GET /api/v1/admin/metrics` 指标

### 举报
- `POST /api/v1/reports`（登录用户举报 question/answer/public_post）
- `GET /api/v1/admin/reports?status=`：**本次新增** `targetTitle`、`targetExcerpt`，运营无需再单独查内容
- `POST /api/v1/admin/reports/{id}/handle`（dismiss/remove，记录处理人）

### 测试
- `AuthFlowTests`、`ProductionAuthTests`、`QuestionFlowTests`、`ModerationFlowTests`、`AdminContextTests`（本次新增）
- 当前全量 `mvn test`：**35/35 通过**；真实 MySQL 8.0 冒烟 18 项通过

## 7. 本模块验收主线

- 公开流程：游客浏览 → 学生注册/提问 → 运营审核通过 → 问题公开 → HR 回答 → 学生查看回答；
- 私密流程：学生私密提问 → HR 认领 → 回答/追问 → 学生结单 → 运营审核脱敏公开 → 公开沉淀可见；
- 权限：未注册不可发帖、学生不能进运营后台、运营可审私密内容并留痕。
