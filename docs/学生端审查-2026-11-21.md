## 正常通过的主要流程

- 游客浏览公开问题、关键词搜索、空结果反馈；最新/热门/推荐切换及最近一天筛选。
- 游客提问进入登录；学生注册、已有账号登录、退出确认，以及退出后受保护页面返回登录。
- 普通问题提交和详情展示、题主自己的待审问题可见、未回答问题撤回。
- 标签选择、最多五项限制。
- 个人昵称修改后同步顶栏；个人资料编辑保存；合法头像上传。
- 点赞/收藏写入与取消、不感兴趣及撤销、举报提交。
- 只有题主可追问：非题主请求返回 403；新追问明确携带具体主回答。
- 学生详情和个人页的手机宽度未发现横向溢出；已运行的浏览器主流程未捕获页面脚本异常。

## 修复建议与范围

先处理 S01–S04，再处理 S05–S08，最后完善 S09–S12。会话和注册涉及共享认证代码时，应只围绕学生流程补适配，并检查既有角色约束，不能顺带扩展 HR 或运营功能。

S08 的补入口限定学生自己的追问；S09 的通知应与现有 HR 通知区分接收角色，已读不改变业务状态。S06 建议将登录账号与游客历史分开保存，退出或切号时重载对应历史，不把本机共享记录当作跨设备个人历史。

本轮没有运行全量 Maven 测试或重新构建，主要通过浏览器操作、隔离 API 对照和定向网络异常模拟审查交互；此前 104 项自动测试通过不能替代本次学生端验收。这份清单不将真实短信和 HR 身份认证等已明确暂缓事项算作新增故障。
