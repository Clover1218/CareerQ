# 回答楼层与追问关联：协作说明

2026-11-21，用户已授权本轮跨公共回答区与学生追问入口的必要修改。其他学生功能和第三、第四阶段计划保持原安排。

## 已实现的规则

- 同一 HR 可以在一道公开问题下发表多个独立主回答；以回答 ID 作为楼层依据，按发布时间、ID 正序展示。每条回答的点赞、举报、状态和作者撤销操作独立。
- 只有题主能在某条已发布主回答下追问；请求同时指定主回答和其 HR 作者。HR 只能回复发给自己的已发布学生追问，不能创建学生追问或审核。
- 主回答正文直接展示，楼内追问默认折叠；允许同时展开多个回答的追问。HR 在楼内可选择具体追问，草稿按回答分别保存，避免同一 HR 的不同回答串写。
- 公共卡片和详情使用同一份前端分组函数；学生“我的问答”复用卡片后得到相同分组，无需修改其页面布局。
- HR 待回复按追问统计、列表按问题去重的规则保留；详情定位先展开所属楼层，再高亮目标追问。
- HR 工作台“我回答过的”本人摘要、详情中的本人主回答和追问回复均提供常显撤销按钮，确认后执行，成功后刷新内容和待办。只有作者可以撤销已发布或待审核的本人回答。
- 回答与追问回复区分作者撤销和运营下架：`removalSource=author/operator`；旧移除记录使用 `unknown`，只显示“已移除”。直接下架与举报下架共用计数逻辑，重复处理不重复扣数、不改写首次来源，举报处理留人工记录。
- 已隐藏主回答和追问如果仍有可见下级讨论，读取接口仅返回空白正文占位；不公开原文和互动计数，不接收对隐藏主回答的新追问。已存在的已发布学生追问继续允许其目标 HR 回复。

## 接口与数据库

- `POST /questions/{id}/followups` 必须同时传 `rootAnswerId` 和 `hrId`，缺少具体主回答返回 400。当前仅接受新版格式。
- 问题详情的追问和回答时间线追问项返回 `rootAnswerId`；HR 回复继续使用既有 `followupId`。
- 运营待审项按需返回 `rootAnswerId`、`followupId`，便于后续页面展示上下文。
- V12 建立追问与主回答关联；V13 停用仍无关联的记录及其回复，并重算受影响问题的发布数量。已执行迁移不改写，原始数据行保留但不参与展示、待办和审核。
- V14 增加回答移除来源、操作者、时间，并修复已有公开问题的回答计数；仅公开来源字段，不公开操作者身份。已发布回答和追问回复移除时计数减一，待审/驳回内容不扣，首次移除后保持来源不变。
- 其他开发分支必须同步具体主回答字段后联调，不再通过自动选择回答接受缺少目标的请求。
- 原有汇总计数字段语义保留，卡片入口称“问答互动”，展开区域明确区分主回答数与参与 HR 人数。

## 文件与影响范围

| 范围 | 文件或模块 | 改动 |
|---|---|---|
| 公共展示 | `frontend/src/components/FeedCard.vue` | 按回答分组、楼内追问、独立草稿和回复目标；公开列表和学生我的问答均使用 |
| 公共详情 | `frontend/src/views/QuestionDetailView.vue` | 主回答楼层、指定回答追问、展开与定位 |
| 共用逻辑 | `frontend/src/utils/answerThreads.ts`、`FollowupDiscussion.vue` | 分组与详情追问展示，安全占位 |
| 前端契约 | `frontend/src/api/index.ts` | 具体回答为必填请求参数，撤销返回更新后的回答 |
| 追问后端 | Followup DTO / DO / DAO / Service | 关联保存、归属校验、必填目标验证、脱敏占位 |
| 公开读取 | AnswerDao、QuestionServiceImpl、ThreadItemView | 全部独立回答、主回答占位和时间线关联 |
| 运营接口 | AdminService、AdminServiceImpl | 附加楼层与追问上下文 |
| 数据与说明 | V12 / V13、DemoDataSeeder、接口契约、OpenAPI | 回答关联、停用无归属记录、演示数据与当前协议 |

公共展示负责人应重点审查卡片结构与互动，学生模块负责人应确认追问入口和我的问答适配，HR 负责人维护回复与待办。此文记录协作范围，不代替人类 PR 审查。

## 需要后续考虑的产品选择

| 事项 | 当前默认 | 后续可选 |
|---|---|---|
| 排序（用户已确定） | 主回答按发布时间正序，越后发越靠下 | 当前不做热度排序 |
| 追问资格（用户已确定） | 仅题主本人 | 其他学生参与留待功能完善后另行讨论 |
| 原回答隐藏后 | 空白占位，保留讨论，已有追问可继续回复 | 关闭旧追问回复，需同步处理已有待办 |
| 状态来源（已实现） | 明确显示作者撤销或运营下架，旧来源不明时显示“已移除” | 当前不增加恢复或历史内容展示 |
| 主回答数量较多 | 当前仍取整道题的时间线 | 另设计回答区分页，不能复用问题池游标 |

登录、学生提问表单、个人资料、导航、独立运营页面、真实通知和原创帖不在本轮实现范围。

2026-11-21 已按用户决定移除未指定回答的额外展示区并停用旧提交格式。学生个人页面的浏览历史不在此次改动范围。
