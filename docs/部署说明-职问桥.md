# 《职问桥》部署说明

> 项目代号：**CareerQ**　｜　后端：Spring Boot 3 + Java 21 + MySQL 8　｜　前端：Vue3 + TypeScript（队友负责）
> 关联：[`技术方案-职问桥.md`](技术方案-职问桥.md)、[`接口契约-职问桥.md`](接口契约-职问桥.md)、[`../backend/README.md`](../backend/README.md)

## 1. 架构与部署拓扑

```text
浏览器
  │ HTTPS
  ▼
反向代理（Caddy / Nginx）
  ├── /            → 前端静态资源（Vue3 构建产物）
  └── /api/*       → Spring Boot :8080（同域，Cookie 会话最省事）
                        │
                        ├── MySQL 8
                        └── 内容安全 API / 短信服务（可选）
```

- 前后端**同域反向代理**是推荐方式：Cookie 会话 + CSRF 无需处理跨域。
- 若前端单独部署在另一域名，需配置 `careerq.cors.allowed-origins`，并保证 HTTPS。

## 3. 本地开发（无需 MySQL）

后端默认 `dev` profile：H2 内存库 + MySQL 兼容模式。

```bash
mvn -f backend/pom.xml spring-boot:run
```

| 地址 | 用途 |
|---|---|
| http://localhost:8080/api/v1/system/health | 健康检查 |
| http://localhost:8080/swagger-ui.html | Swagger UI |
| http://localhost:8080/h2-console | H2 控制台（`jdbc:h2:mem:careerq` / `sa` / 空密码） |

## 4. 生产部署

### 4.1 初始化 MySQL

```sql
CREATE DATABASE careerq DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'careerq'@'%' IDENTIFIED BY '<强密码>';
GRANT ALL PRIVILEGES ON careerq.* TO 'careerq'@'%';
FLUSH PRIVILEGES;
```

表结构由 Flyway 在应用启动时自动迁移，**无需手工建表**。

### 4.2 构建

```bash
mvn -f backend/pom.xml clean package -DskipTests
# 产物：backend/target/careerq-backend-0.1.0-SNAPSHOT.jar
```

### 4.3 启动

```bash
export DB_URL='jdbc:mysql://127.0.0.1:3306/careerq?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai'
export DB_USERNAME='careerq'
export DB_PASSWORD='<强密码>'
export SPRING_PROFILES_ACTIVE='prod'
export CAREERQ_SMS_DEV_MODE='false'   # 关闭固定验证码，接入真实短信服务商

java -jar backend/target/careerq-backend-0.1.0-SNAPSHOT.jar
```

关键环境变量：

| 变量 | 必填 | 说明 |
|---|---|---|
| `DB_URL` / `DB_USERNAME` / `DB_PASSWORD` | 是 | MySQL 连接 |
| `SPRING_PROFILES_ACTIVE` | 是 | `prod` |
| `CAREERQ_SMS_DEV_MODE` | 建议 | 生产必须 `false` |
| `CAREERQ_CORS_ALLOWED_ORIGINS` | 视部署 | 前端跨域时填写，同域部署留空 |

### 4.4 systemd 示例

```ini
[Unit]
Description=CareerQ backend
After=network.target

[Service]
User=careerq
WorkingDirectory=/opt/careerq
EnvironmentFile=/etc/careerq/backend.env
ExecStart=/usr/bin/java -jar /opt/careerq/careerq-backend-0.1.0-SNAPSHOT.jar
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

### 4.5 Caddy 反向代理示例（同域）

```caddyfile
example.com {
    encode gzip
    handle /api/* {
        reverse_proxy 127.0.0.1:8080
    }
    handle {
        root * /var/www/careerq
        try_files {path} /index.html
        file_server
    }
}
```

> 同域部署时 `careerq.cors.allowed-origins` 留空即可，Cookie 会话最稳定。

### 4.6 Nginx 等价配置

```nginx
server {
    listen 443 ssl;
    server_name example.com;

    root /var/www/careerq;
    index index.html;

    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

## 5. 健康检查与运维

| 项 | 做法 |
|---|---|
| 健康检查 | `GET /api/v1/system/health` 或 `GET /actuator/health` |
| 日志 | 应用日志输出到 stdout，交给 systemd/journald 或容器日志收集 |
| 备份 | `mysqldump` 每日全量；保留 7—30 天 |
| 升级 | 先备份 → 替换 jar → 重启；Flyway 自动执行新迁移 |
| 回滚 | 回退 jar；若含破坏性迁移，需按备份恢复数据库（迁移脚本请保持向后兼容） |
