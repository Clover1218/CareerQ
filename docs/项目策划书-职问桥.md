## 一、项目名字

**推荐主名称：职问桥**

| 名称 | 含义 | 适合场景 |
|---|---|---|
| 职问桥 | 学生的问题与 HR 的经验之间的一座桥，公开、异步、可沉淀 | **推荐主品牌** |
| 职答 | 职场人回答职业问题，简洁直接 | 产品名 / Web 站点名 |
| 职场回声 | HR 的观点被学生看见、点赞、回应，形成回声 | 内容社区感更强 |
| 前辈请回答 | 突出「HR / 职场前辈—学生」的问答关系 | 活动感强，适合冷启动 |
| 职途问答库 | 强调结构化、可检索、可沉淀 | 偏工具和资料库 |

- **Slogan**：让好问题遇见对的人，让经验公开沉淀。
- **定位一句话**：面向大学生与 HR 的「**公开问答库 + 私密问答工单**」混合平台，异步、结构化、可审核；不做实时 IM 与社交关系。

## 二、项目概述

「职问桥」连接大学生与 HR / 职场人。学生有两个入口：**公开提问**（进入公共问题池，任何人可见）或**私密工单**（仅自己与认领 HR 可见，异步问答）。HR 可以公开发表职业观点，也可以从问题池选答或认领私密工单。

产品不是「社交平台」，而是「**可沉淀的问答知识库 + 有限私密咨询通道**」：公开内容可检索、可精选、可审核；私密内容仅限异步工单，全程留痕、同样受审核约束，**不提供实时聊天、好友关系与即时消息**。

## 三、背景与问题

具备双边资源：一端是熟悉职业发展和企业人力资源管理的 HR，另一端是有职业困惑的学生。双方有交流意愿，但直接对话存在隐私、安全、内容不可控与监管问题。

因此把「直接对话」拆成两种受控形态：

1. **公开异步问答**：学生公开提问，HR 公开回答，内容可审核、可沉淀；
2. **私密异步工单**：学生不愿公开的问题（简历、薪资、求职困境）进入私密池，由 HR 认领后异步解答，用户确认关闭后可**主动选择脱敏公开**成为公共内容。

两者都不提供实时私聊，平台始终保留审核与下架能力。

## 四、产品定位

- **产品名**：职问桥
- **产品形态**：公开问答库 + 私密问答工单（混合）
- **产品载体**：**Qoder Sites 托管的响应式 Web 站点**（比赛强制平台），兼容手机与桌面浏览器
- **核心用户**：大学生、HR / 职场答主、平台运营方
- **明确不做**：实时聊天、好友关系、即时消息、匿名树洞、招聘投递、简历交易、付费咨询
- **边界说明**：私密工单是**异步、结构化、留痕**的问答单据，不是聊天；HR 与用户不得交换联系方式

**核心价值**：

- 对学生：既能公开获取真实经验，也能就敏感问题获得一对一（异步）建议，降低信息差；
- 对 HR：低成本表达观点、建立专业形象、影响潜在人才；
- 对平台：公开内容形成可复用内容库，私密问答提升提问意愿与留存。

## 五、核心机制

- **学生端（公开路径）**：发布问题 → 选择标签 → 等待 HR 回答 → 点赞/收藏/标记有用 → 公开追问。
- **学生端（私密路径）**：提交私密问题 → 进入私密池 → HR 认领解答 → 原帖内追问 → 确认关闭归档 → 可选择脱敏公开。
- **HR 端**：浏览公开问题池 / 私密待认领池 → 选择回答；也可主动发布「观点帖」或「话题征集」。
- **平台端**：审核内容（公开与私密同等对待）→ 精选问答 → 运营话题 → 处理举报 → 维护答主。

**关键原则**：所有互动异步、留痕、可审核；私密仅指**可见范围**，不免除审核；不提供任何实时私聊入口。

## 六、功能规划

### MVP 阶段功能

1. **学生提问**：标题、描述、标签（面试准备、简历、行业选择、实习、职业规划等）、**可见性（公开 / 私密）**。
2. **HR 回答**：浏览问题池选择回答；支持「一句话建议」和「详细经验」两种长度。
3. **私密工单**：私密问题池、HR 认领、原帖追问、用户关闭归档、可选脱敏公开。
4. **HR 观点帖**：HR 发布短观点或经验分享，学生点赞、收藏。
5. **互动信号**：点赞、收藏、「有用」标记；不做「踩」和公开负面评分。
6. **精选问答**：运营根据质量与互动生成「本周精选」。
7. **举报与审核后台**：举报入口、禁用词库、AI 初筛、人工复核、下架与封禁。
8. **身份认证**：HR 在职/企业身份认证；学生手机号实名，学校专业可选填。
9. **搜索与标签**：按标签浏览问答；私密内容不进入搜索索引。

### 后续功能

- HR 发起话题讨论，学生参与回应；
- 问答合集与专题页；
- 「HR 观点征集—学生回应—HR 再回应」的循环话题；
- 内容收藏夹与个人成长记录；
- 数据看板：回应率、回答时长、私密解决率、公开沉淀率。

## 七、用户流程

**学生流程（公开）**
注册/认证 → 浏览精选问答 → 发布公开问题并选标签 → 等待回答 → 点赞/收藏/追问 → 形成个人收藏。

**学生流程（私密）**
注册/认证 → 提交私密问题（可选填年级/学历/实习目标）→ 等待 HR 认领 → 收到回答 → 追问复核 → 确认关闭 → 可选脱敏公开。

**HR 流程**
认证 → 浏览公开问题池或私密待认领池 → 选择回答/发布观点 → 获得点赞和「有用」反馈 → 进入精选答主池。

**运营流程**
审核新内容（公开 + 私密）→ 匹配问题与 HR → 推动 24—48 小时内回应 → 精选优质内容 → 处理举报与风险内容 → 审核「私密转公开」申请。

## 八、合规与审核设计

- **实名与身份核验**：HR 需任职企业或职业身份认证；学生至少手机号实名。
- **内容审核**：公开与私密内容**同一标准**，AI 初筛 + 人工复核；重点拦截政治敏感、就业歧视、虚假招聘、人身攻击、隐私泄露。
- **私密通道风控**：拦截联系方式交换、索要简历、招聘承诺；运营查看私密内容需留审计记录。
- **数据最小必要**：只收集手机号与必要身份标识；HR 展示为「某互联网公司 HR」，不暴露真实姓名。
- **公开脱敏**：私密转公开前默认隐去姓名、企业全称、学校与联系方式，用户可预览确认。
- **未成年人保护**：未满 18 岁限制私密问答范围，增加监护人/学校合规提示。
- **免责声明**：平台为职业发展交流项目，不代表学校官方就业指导平台；回答为个人观点，不构成招聘承诺。
- **平台强制标识**：按 Qoder Sites 要求展示 AI 生成内容标识，不规避。
- **应急机制**：举报处理时限、违规内容下架、账号封禁、重大风险人工介入。

> 具体合规要求建议在上线前咨询法律或平台合规专业人士。

## 九、冷启动方案

**第一阶段：邀请制跑通闭环**

- 邀请 10—15 位愿意分享的「首批答主」；
- 邀请 1—2 个学院或专业的学生；
- 运营先抛出第一批高质量问题，定向邀请 HR 回答；
- 核心指标：**问题能否在 24—48 小时内得到有效回应**（公开与私密分别统计）。

**第二阶段：内容沉淀与开放注册**

- 形成 100 条以上真实问答后开放学生注册；
- 用「本周精选」「热门标签」「HR 观点帖」运营，并推动私密问答脱敏公开；
- 逐步扩大 HR 答主池，保持回答供给。

## 十、指标体系

**核心指标**

- 公开问题回应率；**私密问题认领率**（48h 内被认领比例）；
- 首次回应时长：目标 24—48 小时内；
- **私密问题解决率**（被用户关闭/标记解决）；
- **公开沉淀率**（关闭的私密问题中选择公开的比例）；
- 有效回答率、次周留存、举报处理时长、精选数量与收藏量。

**冷启动成功标准**

- 4 周内，80% 以上提问在 48 小时内获得至少 1 个回应；
- 8 周内，沉淀 100 条以上公开问答；
- 首批 HR 答主中至少 60% 愿意持续参与；
- 无重大内容安全事故。

## 十一、路线图

| 阶段 | 时间 | 重点 |
|---|---|---|
| MVP 开发 | 第 1—4 周 | 提问（公开/私密）、回答、私密工单、点赞收藏、审核后台 |
| 冷启动 | 第 5—8 周 | 邀请 HR 与学生，跑通回应闭环，推动私密转公开 |
| 内容沉淀 | 第 9—12 周 | 精选问答、标签体系、话题讨论、搜索优化 |
| 扩展 | 第 13 周起 | 扩大答主池、开放注册、形成专题内容库 |

## 十二、团队与资源

- **团队规模**：王、季、李 3 名成员共同开发。
- **分工安排**：具体分工待定，后续按能力与比赛要求协商；AI 仅辅助，不计入团队。
- **开发平台**：**Qoder Sites**（比赛强制），提供托管建站、数据库、服务端函数、对象存储与 Cloud Agents。

预算重点：Qoder Sites 套餐/用量、短信或邮件验证服务、审核人力、内容运营、合规咨询。初期不做多端，先完成响应式 Web 站点。

## 十三、主要风险与应对

| 风险 | 应对 |
|---|---|
| HR 参与不足 | 首批邀请制，降低回答成本，设置「一句话建议」 |
| 学生提问质量低 | 提供提问模板和标签，运营筛选后发布 |
| 内容合规风险 | 公开与私密统一审核、AI 初筛 + 人工复核、禁用词库、举报机制 |
| 私密通道被滥用 | 拦截联系方式、禁止索要简历、运营可审阅并留痕、举报兜底 |
| 被误认为学校官方平台 | 明确个人发起项目定位，避免使用学校官方名义 |
| 变成招聘或私聊工具 | 不设实时私聊/好友/即时消息，不设简历投递与付费咨询 |

## 十四、结论

「职问桥」把「直接对话」拆成两种受控形态：公开问答沉淀内容，私密工单解决敏感问题，两者共用一套审核与留痕机制。先用手上 HR 与学生资源跑通「一个问题必有回应」的最小闭环，再把优质私密问答脱敏沉淀为公共内容。这个路径兼顾真实需求与合规可控，适合作为比赛的起步形态。
