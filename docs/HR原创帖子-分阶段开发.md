# HR 原创帖子分阶段开发

2026-11-22。用户确认按端分阶段实现 HR 原创分享。帖子独立于学生问题和 HR 回答；本轮完成第一阶段，后续阶段仍需继续开发和验收。

## 第一阶段：HR 创作与本人管理（已实现）

- HR 在顶部、个人中心和头像抽屉进入 `/hr/posts`，每页五条查看自己的帖子，按草稿、待审核、审核未通过、已撤回、已发布和下架状态筛选。
- `/hr/posts/new` 编写标题、纯文本正文和最多五个固定目录标签，支持预览。自动保存约在停止输入一秒后执行，也可手动保存；草稿保存到后端，不只存于当前页面。
- 本机立即保留未同步编辑。请求失败后停止自动重试，保留输入并提供重试；重新进入可恢复。后端草稿通过 `clientKey` 防止首次保存超时重试产生重复记录。
- 每次保存、提交、撤回、删除带 `version`。服务器锁定本人帖子再核对版本，旧页面不能覆盖新内容。冲突后保留本页内容，提供读取服务器版本及另存新帖；读取前将未同步内容保存为按账号区分的本机备份。
- 提交前必须填写标题和正文，复用规则审核拦截违规内容，未被拦截的内容统一进入 `pending_human`。第一阶段没有运营审核入口和公开阅读入口，帖子不会因点击提交而立即公开。
- 待审帖子须先撤回再编辑；已撤回或审核未通过的内容可修改为草稿后重新提交。未通过的原文保留供作者修订。草稿可确认删除，删除后不再出现在本人列表；已提交内容通过撤回管理。
- `published` 和 `removed` 为后续阶段准备的状态。第一阶段没有能将帖子改成 published 的客户端或服务端接口；撤回接口可接续后续发布流程。

标题最多 200 字，正文最多 10000 字，标签最多五项，所有内容以纯文本渲染，不执行正文中的 HTML。作者身份始终来自会话。客户端另传可选 `X-CareerQ-Hr-Id` 比对当前页面身份，错号返回 40902，不以客户端 ID 决定作者。

## 数据与接口

V18 新建 `hr_posts` 和 `hr_post_tags`，不复用、迁移或开放历史 `posts` 表。V1–V17 保持原内容。新增表使用作者/状态/编号索引、作者与 `client_key` 唯一索引，标签复用现有固定目录。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/v1/hr/posts?status=all&cursor=&limit=5` | 当前 HR 的列表，ID 倒序，支持状态筛选 |
| GET | `/api/v1/hr/posts/{id}` | 本人的完整帖子 |
| POST | `/api/v1/hr/posts/drafts` | 保存首份草稿，传 clientKey、title、body、tags |
| PUT | `/api/v1/hr/posts/{id}/draft` | 保存编辑，传 version、title、body、tags |
| POST | `/api/v1/hr/posts/{id}/submit` | 传 version，规则拦截或提交待审核 |
| POST | `/api/v1/hr/posts/{id}/withdraw` | 传 version，将待审/已发布改为已撤回 |
| DELETE | `/api/v1/hr/posts/{id}/draft` | 请求体传 version，仅删除 draft 状态 |

未登录返回 401，非 HR 返回 403；其他 HR 的内容统一 404。缺字段、超长、未知标签和无效游标返回 400；状态不符和旧版本返回 409。`version` 从 1 开始，每次有效更新增加 1。首次建稿的相同作者/clientKey 返回已有记录，不把重复请求当作更新或再次提交。

详情含 `id/title/body/tags/status/version/createdAt/updatedAt/submittedAt`；列表用 `excerpt` 替代完整正文，页结果为 `items/nextCursor`。作者不能从请求体修改 status、authorId、version 或审核结果。提交产生 `targetType=hr_post` 机器审核记录，为第二阶段提供接入点；现有运营队列暂不读取该类型。

## 第二阶段：运营审核（待实现）

1. 运营队列识别独立的 hr_post 类型及当前提交版本，提供上下文和通过/驳回/下架。
2. 对已撤回、已修改或旧版本的审核请求返回冲突，不能把旧正文审核结果用于新正文。
3. 通过后为 published，驳回保留作者可修订内容，运营下架与作者撤回区分。
4. 接入 HR 审核结果通知，不将帖子 ID 当作问题 ID 塞入既有问答通知。

## 第三阶段：公开展示与学生互动（待实现）

提供“HR 分享”列表及帖子详情，仅展示已发布内容；接入点赞、收藏、举报和学生收藏列表。每个新目标类型均需明确可见性、互动计数和下架后的处理；未发布内容仍不得借公开查询或互动读取。

学生提问/追问和原 HR 问答接口语义保持不变。本轮未改学生页面和运营页面，也不开放评论、私信、真实认证或站外推送。

## 验证

本轮后端 `HrPostFlowTests` 四项专项覆盖角色与作者隔离、错号检查、重复建稿、版本冲突、提交/撤回/修改、规则拦截与校验、五条分页及删除、待审内容不进入公开问答。前端类型检查与浏览器验证结果记录在当天 Codex 日志；没有以专项通过替代全项目回归或生产 MySQL 验证。
